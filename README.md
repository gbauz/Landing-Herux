## Levantar el proyecto

Necesitas Node.js 18+ y npm.

```
git clone <url-del-repo>
cd ux-day-landing
npm install
npm run dev
```

La app quedará corriendo en `http://localhost:5173` (o el puerto que indique la terminal).

## Build de producción

```
npm run build
```

Esto genera la carpeta `dist/` lista para desplegar.
